# 🎮 Dev City

Projeto web interativo desenvolvido com **HTML, CSS e JavaScript**, inspirado em interfaces de seleção de personagens de jogos de mundo aberto.

O projeto permite navegar entre personagens disponíveis e utilizar a câmera do dispositivo para capturar uma selfie, integrando recursos do navegador a uma interface personalizada.

## 🚀 Funcionalidades

- **Seleção de personagens:** interação com os personagens exibidos na interface.
- **Acesso à câmera:** abertura da câmera do dispositivo para capturar uma selfie.
- **Captura de imagem:** utilização do Canvas para processar a foto capturada.
- **Exibição da selfie:** apresentação da imagem na interface após a captura.
- **Identificação do personagem:** exibição do nome associado à seleção ou à selfie.

## 🛠️ Tecnologias utilizadas

- HTML5 — estrutura da aplicação.
- CSS3 — estilização e organização visual da interface.
- JavaScript — lógica, eventos e manipulação dos elementos da página.
- Canvas API — processamento e captura da imagem.
- MediaDevices API — acesso à câmera do dispositivo.

## 💻 Como executar o projeto

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Execute o arquivo `index.html` utilizando uma extensão como Live Server.
4. Autorize o acesso à câmera quando solicitado pelo navegador.

**Observação:** o acesso à câmera requer uma origem segura, como `localhost` ou uma página publicada em HTTPS, além da permissão do usuário.

## 🎯 Objetivo do projeto

O Dev City foi desenvolvido como projeto de estudo e portfólio, com o objetivo de praticar desenvolvimento frontend, manipulação do DOM, eventos JavaScript e integração com recursos multimídia do navegador.

## 📚 Conhecimentos praticados

- Estruturação de páginas web.
- Estilização de interfaces com CSS.
- Manipulação do DOM e tratamento de eventos.
- Acesso a recursos de hardware por meio de APIs do navegador.
- Captura e exibição de imagens com JavaScript e Canvas.
- Depuração e correção de problemas durante o desenvolvimento.
